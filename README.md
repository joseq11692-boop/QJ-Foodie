# QJ Foodie

Sistema de trabajo para construir una marca de contenido gastronómico al nivel de los mejores creadores del mundo.

## Cómo usar este repo

| Carpeta | Qué contiene |
|---|---|
| [`estrategia/`](estrategia/) | Posicionamiento, nicho y qué hacen distinto los mejores creadores |
| [`contenido/`](contenido/) | Formatos, fórmulas de gancho y estructura de video |
| [`produccion/`](produccion/) | Checklist de grabación, luz, sonido y food styling |
| [`crecimiento/`](crecimiento/) | Métricas, rutina de análisis y plan de los primeros 90 días |
| [`plantillas/`](plantillas/) | Guiones y fichas listas para copiar en cada video |

## Las 5 reglas que comparten los mejores

1. **Un punto de vista reconocible.** Keith Lee es la honestidad, Mark Wiens es la emoción pura, Kenji López-Alt es la ciencia, Joshua Weissman es el "hazlo tú mismo pero mejor". La gente sigue a una *persona*, no a una receta.
2. **El primer segundo lo decide todo.** El plato final, el sonido más crujiente o la frase más provocadora va al principio, nunca al final.
3. **Sonido y textura antes que palabras.** El crujido, el chisporroteo y el queso estirándose venden más que cualquier descripción.
4. **Volumen con sistema.** Publican mucho porque tienen plantillas, días de grabación en bloque y formatos repetibles, no porque improvisen.
5. **Escuchan los datos, no las opiniones.** Retención y compartidos mandan; los likes engañan.
